---
title: $pathResolve
description: Returns a resolved, absolute path to a file or directory.
---

Returns a resolved, absolute path to a file or directory.
## Parameters
| Name  |      Description      | Enforced | Default Value |
|-------|-----------------------|----------|---------------|
| Paths | The paths to resolve. | Yes      | None          |
## Example
```eats
$pathResolve[...paths]
```
