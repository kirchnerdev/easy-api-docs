---
title: $fileCreatedAt
description: Returns the time when the file or directory was created.
---

Returns the time when the file or directory was created.
## Parameters
|   Name    |            Description             | Enforced | Default Value |
|-----------|------------------------------------|----------|---------------|
| File Path | The path to the file or directory. | Yes      | None          |
## Example
```eats
$fileCreatedAt[filePath]
```
