Copies a file from one location to another.
## Parameters
|    Name     |        Description         | Enforced | Default Value |
|-------------|----------------------------|----------|---------------|
| Source      | The source file path.      | Yes      | None          |
| Destination | The destination file path. | Yes      | None          |
## Example
```eats
$copyFile[source;destination]
```
