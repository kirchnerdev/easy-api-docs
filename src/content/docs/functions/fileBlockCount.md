Returns the block count of the file or directory.
## Parameters
|   Name    |            Description             | Enforced | Default Value |
|-----------|------------------------------------|----------|---------------|
| File Path | The path to the file or directory. | Yes      | None          |
## Example
```eats
$fileBlockCount[filePath]
```
