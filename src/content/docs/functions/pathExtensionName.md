title: $pathExtensionName
description: Returns the extension name of the given file path.
---

Returns the extension name of the given file path.
## Parameters
| Name |                 Description                 | Enforced | Default Value |
|------|---------------------------------------------|----------|---------------|
| Path | The file path to get the extension name of. | Yes      | None          |
## Example
```eats
$pathExtensionName[path]
```
