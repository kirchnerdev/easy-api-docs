title: $fileChangedAt

---

Returns the time when the file was last changed.
## Parameters
|   Name    |      Description      | Enforced | Default Value |
|-----------|-----------------------|----------|---------------|
| File Path | The path to the file. | Yes      | None          |
## Example
```eats
$fileChangedAt[filePath]
```
