---
title: $pathRelative
description: Returns the relative path between two absolute paths.
---

Returns the relative path between two absolute paths.
## Parameters
| Name |     Description      | Enforced | Default Value |
|------|----------------------|----------|---------------|
| From | The base path.       | Yes      | None          |
| To   | The path to resolve. | Yes      | None          |
## Example
```eats
$pathRelative[from;to]
```
