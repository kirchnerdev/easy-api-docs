---
title: $fileModifiedAt
description: Returns the time when the file or directory was last modified.
---

Returns the time when the file or directory was last modified.
## Parameters
|   Name    |            Description             | Enforced | Default Value |
|-----------|------------------------------------|----------|---------------|
| File Path | The path to the file or directory. | Yes      | None          |
## Example
```eats
$fileModifiedAt[filePath]
```
