title: $fileBlockSize

Returns the block size of the file or directory.
## Parameters
|   Name    |            Description             | Enforced | Default Value |
|-----------|------------------------------------|----------|---------------|
| File Path | The path to the file or directory. | Yes      | None          |
## Example
```eats
$fileBlockSize[filePath]
```
