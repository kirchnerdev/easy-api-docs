---
title: $isSymbolicLink
description: Returns whether the given path is a symbolic link.
---

Returns whether the given path is a symbolic link.
## Parameters
|   Name    |      Description      | Enforced | Default Value |
|-----------|-----------------------|----------|---------------|
| File Path | The path to the file. | Yes      | None          |
## Example
```eats
$isSymbolicLink[filePath]
```
